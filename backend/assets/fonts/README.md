# PDF fonts

Used by `src/services/pdfExport.js` for the daily call report.

| File | Font | Licence |
|---|---|---|
| `NotoSans-Regular.ttf`, `NotoSans-Bold.ttf` | Noto Sans (Latin, Greek, Cyrillic: accented names such as Hernández, Muñoz) | SIL Open Font License 1.1 — `OFL-NotoSans.txt` |
| `NotoEmoji-Regular.ttf` | Noto Emoji (monochrome, black-and-white emoji) | SIL Open Font License 1.1 — `OFL-NotoEmoji.txt` |

The OFL allows the fonts to be bundled and redistributed with software, free
of charge, as long as the licence and copyright notice travel with them and
the fonts are not sold on their own. Both copyright notices are at the top of
the licence files: Copyright 2022 The Noto Project Authors (Noto Sans),
Copyright 2013 Google LLC (Noto Emoji).

Source: the Google Fonts releases of these fonts, as packaged in the npm
packages `@expo-google-fonts/noto-sans` 0.4.2 and `@expo-google-fonts/noto-emoji`
0.4.8 (files copied unmodified).
